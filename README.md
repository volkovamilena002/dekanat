# Мой деканат — концепт «Цифрового деканата будущего»

Прототип личного кабинета студента для конкурса. **Не официальный сервис вуза. Все данные вымышленные.**

## Запуск локально

Нужен только Node.js 20+.

```bash
npm install
npm run dev:local
```

Команда сама поднимет PostgreSQL (пакет embedded-postgres), создаст `.env.local` со случайным
паролем базы, зальёт вымышленные данные и запустит сайт на http://localhost:3000.

Другие команды: `npm run db:start` — только база; `npm run db:setup` — пересоздать демо-данные;
`npm run db:migrate` — применить миграции.

## Автотесты

```bash
npm run test:e2e
```

Playwright прогоняет сценарии в браузере против **продакшен-сборки** (`next build` + `next start`
на порту 3100) и **отдельной базы** `dekanat_e2e`, которая пересоздаётся перед каждым прогоном.
Данные для разработки не трогаются. Нужен установленный Google Chrome. Если его нет, выполните
`npx playwright install chromium` и задайте `PW_BUNDLED=1`.

| Файл | Что проверяет |
|---|---|
| `e2e/student.spec.ts` | обязательное ядро ТЗ: «Сегодня», профиль, расписание и .ics, успеваемость, уведомления, плашка «концепт» на каждой странице |
| `e2e/requests.spec.ts` | справка от заявки до проверки подлинности: студент → сотрудник → уведомление → документ → `/verify`; отмена; ответ на уточнение |
| `e2e/electives.spec.ts` | запись на элективы: лимит, места, отказ, серверная защита от «разблокированной» кнопки |
| `e2e/staff-schedule.spec.ts` | перенос, отмена, смена аудитории; пересечения; изменения видят только студенты группы |
| `e2e/security.spec.ts` | без входа ничего нельзя открыть, чужая заявка → 404, разделение ролей, флаги cookie, выход, лимит попыток входа, заголовки, нет секретов в HTML |
| `e2e/mobile.spec.ts` | все экраны на ширине 360 px без горизонтальной прокрутки |
| `e2e/theme.spec.ts` | переключатель темы: выбор сохраняется и приходит с сервера без мигания |
| `e2e/a11y.spec.ts` | доступность WCAG 2.1 AA (axe-core) на всех экранах в светлой и тёмной теме; навигация с клавиатуры |

Отчёт с подробностями падений: `npx playwright show-report`.

**Демо-видео:** `npm run video` — после всех автотестов браузер сам проходит сценарий
[docs/video-script.md](docs/video-script.md) и собирает `video/dekanat-demo.mp4` (720p, с озвучкой),
`.webm` без звука и субтитры `.srt` отдельным файлом (вшить в кадр: `VIDEO_SUBTITLES=1`). Озвучка — нейроголос Microsoft через edge-tts; один раз
подготовьте окружение Python (иначе видео соберётся без звука):

```bash
python -m venv .venv && .venv/Scripts/python -m pip install edge-tts imageio-ffmpeg
```

Голос по умолчанию — Дмитрий; женский: `VIDEO_VOICE=ru-RU-SvetlanaNeural npm run video`.
Озвученные фразы кэшируются в `video/voice/`, повторная сборка их не перезапрашивает.

**PDF-отчёт для жюри:** `npm run report` → `report/dekanat-ai-report.pdf` (идея, работа с ИИ,
промпты, ошибки ИИ, проверки, безопасность, экраны). После деплоя:
`REPORT_SITE_URL=https://… npm run report`; автор на обложке — `REPORT_AUTHOR="…"`.

**Скриншоты для отчёта:** `npm run screenshots` сохраняет экраны с телефона (светлая и тёмная тема)
и с компьютера в `docs/screenshots/`.
